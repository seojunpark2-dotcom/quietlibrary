# Quiet Library

도서관의 차분한 분위기에서 공부와 독서에 몰입할 수 있도록 만든 무료 웹 집중 타이머입니다.

🔗 [사이트 방문하기](https://quietlibrary.kr/)

## 주요 기능

- 원하는 집중 시간을 분 단위로 직접 설정
- 30분 · 60분 · 90분 빠른 시간 선택
- Dark / Light 서재 테마 선택
- 필기소리 재생, 끄기 및 음량 조절
- 일시정지와 메인 화면으로 돌아가기
- 타이머 완료 시 축하 화면 표시
- 설정 시간에 따라 크기가 달라지는 책 이미지 효과
- 사이트 소개, 기능 소개, 문의, 개인정보처리방침 독립 페이지
- 메뉴와 주요 이동 버튼 클릭 효과음

## 사용 방법

1. 첫 화면에서 원하는 분위기(Dark 또는 Light)를 고릅니다.
2. **도서관 입장하기**를 누릅니다.
3. 집중 시간을 직접 입력하거나 빠른 선택 버튼을 이용합니다.
4. **집중 시작하기**를 누르고 타이머와 함께 공부를 시작합니다.
5. 필요할 때 필기소리와 음량을 조절하거나 타이머를 일시정지할 수 있습니다.

## 기술 구성

별도 프레임워크나 빌드 과정 없이 HTML, CSS, JavaScript로 제작한 정적 웹사이트입니다.

- HTML5
- CSS3
- Vanilla JavaScript
- HTML5 audio를 통한 MP3 직접 재생
- Vercel 정적 배포

## 로컬에서 실행하기

정적 HTTP 서버로 저장소 루트를 열어 확인합니다. 루트 경로를 사용하는 메뉴·음원·스크립트가 있으므로 파일을 더블클릭하는 방식 대신 HTTP 서버를 사용하세요. 브라우저 스크립트를 수정한 뒤에는 `node scripts/sync-csp.cjs`를 실행해 SRI 무결성과 CSP 해시를 함께 갱신합니다. Vercel 빌드에서도 이 명령을 실행합니다.

`node scripts/check-site.cjs`로 모든 페이지의 스크립트 무결성·광고 로딩 범위·모바일 메뉴 마크업·시간별 시작 링크를 검사합니다.

필기소리는 운영자가 저작권을 보유한 음원(`audio/library-ambience.mp3`)을 사용하며, 사용자가 집중 시작 버튼을 누른 뒤 직접 재생됩니다. 원본 전체 길이를 유지한 64kbps 스테레오 MP3이며 반복 재생, 음량 조절, 음소거와 일시정지를 지원합니다.

## Vercel 배포

1. 이 저장소를 GitHub에 올립니다.
2. Vercel에서 **Add New → Project**를 선택합니다.
3. 이 저장소를 연결한 뒤 배포합니다.
4. `vercel.json`의 빌드 명령으로 스크립트 무결성 정보를 갱신하고 정적 사이트로 배포됩니다.
5. GitHub의 `main` 브랜치에 변경 사항을 올리면 Vercel이 새 배포를 진행합니다.

## 광고 및 개인정보 안내

Google AdSense를 이용하는 경우 `ads.txt` 파일을 사이트 최상위 경로에 유지해야 합니다. 개인정보처리방침은 [privacy.html](./privacy.html)에서 확인할 수 있으며, 광고 쿠키 및 자체 음원 파일 제공 방식을 안내합니다.

광고 런타임은 `/guides/글주소`의 본문 페이지에만 삽입합니다. 타이머·완료 화면과 개인 기록 입력 페이지는 제외합니다. 메인에는 사이트 확인용 `google-adsense-account` 메타 태그를 유지합니다. 광고 슬롯 ID를 임의로 만들지 않으며 자동 광고의 형식·영역·페이지 제외, 지역별 CMP 동의 메시지, 심사 신청은 AdSense 계정에서 별도로 확인해야 합니다.

정적 파일에는 SHA-256 기반 strict CSP와 SRI를 적용합니다. 신뢰한 스크립트만 실행하고, Google 광고 코드가 동적으로 불러오는 스크립트는 `strict-dynamic`으로 허용합니다. 광고 요청 도메인 변화에 대응하도록 HTTPS 프레임·연결을 허용하며 미디어는 동일 출처로 제한합니다. 스크립트를 새로 추가하면 `scripts/sync-csp.cjs`의 목록에도 등록하세요.

## 콘텐츠와 검증 범위

가이드의 학습 사례·기록 수치는 가상 예시로 표시합니다. `guides/timer-walkthrough.html`의 화면은 실제 서비스 화면에 설명용 데이터를 넣어 촬영한 것입니다. 운영자의 실제 학습 경험이나 사용자 성과로 주장하지 않습니다. 실제 경험이 제공되면 출처와 작성일을 확인하고 해당 사례를 보강할 수 있습니다. 변경 사항은 AdSense 승인을 보장하지 않습니다.
