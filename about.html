ABOUT QUIET LIBRARY

온라인에 만들었습니다.

Quiet Library는 도서관에 앉아 책을 펴는 순간의 차분함을 화면 안에 담은 무료 집중 타이머입니다.

왜 만들었나요?

공부를 시작하기 위해 매번 완벽한 장소와 긴 계획을 준비해야 한다는 부담을 줄이고자 만들었습니다. 도서관에 들어가 자리를 정하고 책을 펴는 흐름을 웹에서 간단히 재현해, 이용자가 지금 할 한 가지와 집중 시간부터 결정할 수 있도록 설계했습니다. 회원가입 없이 바로 사용할 수 있으며 기록 기능도 현재 브라우저 안에서 작동합니다.

누구를 위한 공간인가요?

시험 공부를 시작하려는 학생, 긴 글을 읽을 시간이 필요한 직장인, 논문·자격증·독서처럼 한 가지 일에 천천히 몰입하고 싶은 모든 이용자를 위한 공간입니다.

누가 운영하나요?

Quiet Library 운영자가 집중 타이머와 공부 가이드를 관리합니다. 문의 창구는 seojunpark2@gmail.com입니다. 관련 학위나 자격을 인증하는 서비스가 아니라, 무료 타이머의 사용법과 학습 계획 예시를 제공하는 사이트입니다.

콘텐츠 작성 기준

공부 가이드는 타이머를 실제 공부에 적용할 수 있도록 목표 설정, 세션 구성, 과목별 예시, 방해가 생겼을 때의 대처, 종료 후 점검을 포함합니다. 다른 글을 요약하는 데 그치지 않고 Quiet Library에서 바로 실행할 수 있는 표·체크리스트·기록 양식을 제공합니다. 일반적인 학습 정보를 제공하며 의료·심리·성적 향상을 보장하는 조언은 제공하지 않습니다.

콘텐츠는 어떻게 만들고 확인하나요?

2026년 11월 가이드 개정에는 AI 도구를 사용해 초안 작성, 중복 문단 정리, 문장 검토와 기능 점검을 진행했습니다. 기능 설명은 사이트의 실제 화면·동작과 대조하고 연구를 소개하는 부분은 연결한 원문의 내용과 적용 범위를 확인합니다. 가상 예시와 실제 기능 점검은 구분해 표시합니다.

30분 가이드는 과제 범위를 줄이는 판단, 60분 가이드는 개념 적용과 오답 해석, 90분 가이드는 시험 제한 시간과 복습 조건을 다룹니다. 정확하지 않은 설명은 문제 위치와 재현 과정을 보내주시면 확인할 수 있습니다.

자료와 사례를 구분하는 기준

학습 연구를 소개할 때는 원문을 연결하고 연구가 다룬 활동과 사이트가 제안하는 시간표를 구분합니다. 화면 캡처는 기능 설명 자료이며 학습 효과를 입증하는 자료가 아닙니다. 가상 사례를 실제 운영자나 이용자의 경험으로 소개하지 않습니다. 현재 공개한 사례만으로 성적이나 집중력 개선을 입증할 수 없습니다.

작성 주체는 Quiet Library 운영자입니다. 공개적으로 확인되지 않은 학위·자격·지도 경력을 주장하지 않습니다. 콘텐츠 오류 제보는 문의 이메일로 받으며, 오류 위치와 확인 가능한 자료를 보내주시면 검토에 도움이 됩니다.

학습 자료와 적용 범위

회상 활동의 참고 자료는 Roediger와 Karpicke(2006)의 산문 학습 실험입니다. 반복 읽기와 기억에서 꺼내는 활동을 비교했고 지연된 검사에서 인출 연습의 이점을 관찰했습니다. 모든 과목이나 개인의 성적에 같은 결과가 난다는 뜻은 아닙니다.

Roediger & Karpicke (2006), Test-Enhanced Learning, Psychological Science 17(3), 249–255

분산 연습과 연습 시험의 일반적인 검토는 Dunlosky 등(2013), Improving Students’ Learning With Effective Learning Techniques를 참고합니다. 이 자료들도 Quiet Library를 평가한 연구는 아닙니다.

5-20-5, 10-35-15, 15-55-20 같은 배분과 7일 비교 기간은 실행을 돕는 계획 예시입니다. 최적 비율이나 최소 효과 기간을 검증한 수치가 아니며 사이트 자체의 학습 효과를 측정한 자료도 없습니다.
